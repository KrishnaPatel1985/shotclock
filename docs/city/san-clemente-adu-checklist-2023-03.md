## What the applicant must submit
- Applicant information: name, phone, email, project address, unit size, ADU type (attached, detached, repurposed space), primary use of site.
- Address Exhibit: letter-size sheet with site plan, unit entrances, and property address.
- Site photographs: ADU location as seen from the residence and from the street.
- Coastal approval if applicable: approved Coastal Development Permit or Waiver (Coastal in-concept review with Planning first).
- Signed applicant certification (information accurate; will comply, including recording the deed restriction).
- Before building permit issuance: recorded deed restriction and building impact fee calculation form.
- Planning staff must approve the checklist before the building permit application is submitted.

## Site plan / building permit items referenced
- Site/plot plan with parcel boundaries, dimensions, distances between ADU, primary dwelling and property lines.
- Percolation test if on a septic system (within 5 years, or 10 if recertified).
- Utility connection details for detached / new-construction ADUs.
